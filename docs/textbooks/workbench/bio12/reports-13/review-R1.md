## Flags

1. **Species-area "rectangular hyperbola / saturates / plateau" contradicts the chapter's own power law (book error, propagated; writer item 1).**
 Where: Topic 01 Concept intuition "Limiting conditions" bullet 2 (p. 715); Key concepts item 2 (p. 715); Common pitfalls item 2 "Forgetting that the species–area curve saturates. It is a rectangular hyperbola..." (p. 720/721); Figure 13.1 caption and "plateau" label (pp. 716/717).
 Says now: "richness rises with area, then flattens; it is a saturating curve"; "tracing a rectangular hyperbola: S = C A^z".
 Wrong: S = C A^z (z < 1) is a power law: straight on log-log axes, concave on ordinary axes, no plateau. Ex 3 predicts 79 species at 100 ha with no ceiling, MCQ 3 and the practice items use the same law. NCERT does use "rectangular hyperbola" (and "only up to a limit"), so keep NCERT's wording as the book's but stop teaching it as the law. The key points file already avoids the wording, so the chapter and the revise cards now disagree.
 Fix [NEW], add after the equation block in Key concepts: "NCERT describes the curve on ordinary axes as a rectangular hyperbola. Strictly, S = C A^z with z below 1 is a power law: richness keeps rising, ever more slowly, and the plot is a straight line only on log–log axes." Pitfall 2 [NEW]: "<b>Treating the curve as a straight line, or as one with a hard ceiling.</b> On ordinary axes richness rises steeply and then more slowly as the area grows (NCERT calls this a rectangular hyperbola); it is a straight line only on log–log axes." Limiting bullet 2 [NEW]: "The species–area relationship holds within the range of areas sampled: richness rises with area, ever more slowly, and the curve is not a straight upward line on ordinary axes." Figure 13.1 caption: keep the book's words, append "(NCERT's description; strictly a power law)".
 Kind: biology error / misleading. Source: book. Confidence: certain (85% that founder will keep NCERT's wording, hence the note form).

(a) nudge is null; (b)/(d) are called "invented thresholds" although (b) is a true lower bound.

(a) nudge [NEW]: "<b>(a)</b> misreads 70% lost as 30% lost: 30% is the share that may remain." (b) nudge [NEW]: "<b>(b)</b> is not the threshold the criterion uses." Key stays (c).
 Kind: MCQ ambiguity. Source: book. Confidence: certain.

5. **"z and C are dimensionless fitted constants" (writer item 2).**
 Where: Topic 01, "A note on units" (p. 716). Wrong: with S a count and A in hectares, C carries area^(−z) (Ex 3: C = 25.1 species per ha^0.25); only z is dimensionless. "C = Y-intercept constant" is true only for log S against log A (the intercept there is log C).
 Fix [NEW]: "<i>S</i> is a pure count and <i>z</i> is dimensionless; <i>C</i> is a fitted constant, the species count at unit area on the fitted line (so it carries units of area<sup>−<i>z</i></sup>)." And in "where": "<i>C</i> = constant (log <i>C</i> is the Y-intercept of the log–log line)". Kind: biology/number. Source: book. Confidence: certain.
