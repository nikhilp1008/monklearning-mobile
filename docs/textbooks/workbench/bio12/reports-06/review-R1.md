### 16. Topic 02, Hardy–Weinberg statements that go too far
Where, says now, fix:
a) Caveats bullet 1: "Break any one and the population evolves." Non-random mating alone changes genotype frequencies but not allele frequencies. Fix [NEW]: "Break any one and the population can depart from equilibrium (a small population, mutation, gene flow or selection changes allele frequencies; non-random mating changes genotype frequencies only)."
b) Caveats bullet 4: "Mutation and recombination ... change allele frequencies very slowly". Recombination does not change allele frequencies (the Precision note says so). Fix [NEW]: "Mutation changes allele frequencies very slowly and recombination only reshuffles existing alleles; natural selection is the main directional force, whereas genetic drift acts by chance."
c) Concept intuition: "if they drift away from the prediction, some evolutionary force is at work, and the size of the gap measures how much." Chance sampling and non-random mating also give gaps; "measures how much" is loose. Fix [NEW]: "some force (or chance, in a small sample) is at work; a large gap suggests a stronger effect."
d) Pitfall 5 and KP: "it is non-random mating that disturbs it": add "(genotype frequencies)". Fix [NEW]: "it is non-random mating that disturbs the genotype frequencies."
Kind: biology (overgeneral). Source: book. Confidence: likely.
