3. Topic 04, 4.3 "Competition's three outcomes" (1), MCQ 3 option (d) nudge, practice 4 answer. Says: "two species competing for the same resource cannot coexist indefinitely", nudge "(d) is irrelevant: even unrelated species compete; relatedness is not the condition", answer "No two species competing for the same limiting resource coexist indefinitely". Wrong: overgeneral; NCERT states Gause's principle for closely related species and only when the resource is limiting; the same part's resource partitioning shows competitors can coexist. The nudge contradicts NCERT's "closely related". Fix [NEW] (1): "Competitive exclusion (Gause's principle): two closely related species competing for the same limiting resource, with the same niche, cannot coexist indefinitely; the competitively inferior one is eliminated (this holds only when the resource is limiting)." MCQ 3 (d) nudge [NEW]: "(d) is not the condition: NCERT states the principle for closely related species, which compete most strongly; what drives exclusion is a shared, scarce resource and the same niche." Practice 4 answer [NEW]: "Two species that use the same limiting resource in the same niche cannot coexist indefinitely: the inferior is eliminated. Resource partitioning (different times or zones) reduces the overlap, so both can persist." Kind: biology. Source: book. Certain.

4. Topic 03, 3.3 Logistic "Premise": "A habitat can support at most K individuals ... beyond it, growth cannot continue."
