MONKLEARNING — LOGO KIT
=======================
Rebuilt from the live site (MonkLearning.com). Wordmark text is converted to
outlines (real Anek Latin paths), so SVGs render identically everywhere with no
font install required.

WHAT'S INSIDE
-------------
svg/   Master vector files — infinitely scalable, editable in Figma/Illustrator.
       Use these for print/posters and anywhere quality matters most.
png/   Transparent rasters at multiple sizes — for slides, web, social, video.
jpg/   Flattened versions on a solid background — for places that reject PNG/SVG
       or transparency (some WhatsApp/print/upload fields).
favicon/ Browser tab icon — favicon.ico (multi-size), PNGs, and an SVG.

THE THREE FORMS
---------------
1. SYMBOL  — the aperture mark alone (square). Best for app icons, avatars,
   watermarks, favicons, tight spaces.
     symbol-color   rings in Ink, dot in Marigold  (use on light backgrounds)
     symbol-white   rings in Paper, dot in Marigold (use on dark backgrounds)
     symbol-red-core alternate red dot
     app-icon       the mark on a rounded Ink tile (best for profile pictures /
                    app stores / any square avatar slot)
2. WORDMARK — "monklearning" alone.
     wordmark        (dark text — on light backgrounds)
     wordmark-white  (light text — on dark backgrounds)
3. LOCKUP   — symbol + wordmark together. This is the PRIMARY logo.
     lockup-horizontal / -white   (default, wide spaces)
     lockup-stacked / -white      (square-ish spaces, posters, profile headers)
   "-white" = the version for dark backgrounds.

QUICK PICKER
------------
Profile picture (round/square)............ png/app-icon/app-icon-512.png
Website header / email signature.......... svg/lockup-horizontal.svg
Poster / large print...................... svg/lockup-stacked.svg
Instagram post on a dark photo............ png/lockup-horizontal-white-2400w.png
WhatsApp / upload that won't take PNG..... jpg/lockup-horizontal-on-paper-2400.jpg
Browser tab............................... favicon/favicon.ico

BRAND SPECS (the final, authoritative values)
----------------------------------------------
Colors:
  Ink       #181818   primary marks & "monk"
  Paper     #FCFAF4   light background / marks on dark
  Marigold  #EEA31F   the focus dot
  Slate     #55565C   "learning"
  Red       #DD4433   alternate dot
Wordmark: lowercase, one word, Anek Latin. "monk" weight 800 (Ink),
  "learning" weight 500 (Slate). Letter-spacing 0em (the loosened, final value).
The mark: aperture / shutter — broken concentric rings (radii 36/19/6,
  strokes 11/9 on a 120-unit grid) closing onto a marigold point.

DON'T
-----
- Don't stretch or squash the logo (scale proportionally).
- Don't recolour the rings or the dot.
- Don't add a space or capital letters to the wordmark.
- Don't place on busy / low-contrast backgrounds; keep clear space around it.
